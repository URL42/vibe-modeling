# Cicero original imports and references

Current printable product: [complete integral-joint design](../../designs/cicero_joined/README.md)
and [head/bust artifacts](../cicero_joined/). This folder preserves the originals,
uniformly scaled master and uncut intermediate head/base pair. Earlier unjoined
face-fit and rejected loose-key head outputs are retired.

## Retained files and audit

Original imports: `2.stl`, `simplified.stl` and
`5352-tsaritsyno-museum-moscow-bust-5(1).3mf`.
Generated references: `scaled_master.stl`, `head_intermediate.stl`,
`base_intermediate.stl`, 20 PNG images and three JSON evidence files.
Including the three originals and this README, the flat folder has **30 files**.
It is a source/reference collection, not a printable manifest build.

The master is uniformly scaled to a 228.6 mm (nine-inch) ear-tip span;
assembled bounds are 437.54 x 342.23 x 569.00 mm. The original scan is preserved.
