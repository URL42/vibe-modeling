# Retired Cicero head-only candidate

Superseded by [the complete integral-joint Cicero design](../cicero_joined/README.md).
The user rejected separate connector keys, the bare neck and the missing bust.
The old generated output directory has been removed; do not print this candidate.

`historical_parts.json` and `historical_assembly.json` preserve the rejected
architecture without registering it as an automatically rebuilt current design.
Source assets and prior review evidence remain historical. `generate.py` is also
a hashed helper dependency of the current generator; retain its bytes. Its main
routine reproduces rejected geometry and must not be used for current builds.
